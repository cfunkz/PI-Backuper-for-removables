Clone

Copy one card straight onto another, without saving a file in between.

Clone erases everything on disk B.

Steps

  1. Plug in both cards. You'll need two readers, or a reader with two slots that shows up as two disks.
  2. Press Refresh.
  3. Set A to the card you're copying from and B to the card you're copying onto.
  4. Click Start clone and check the dialog. It lists both disks, with B marked as the one being erased.

Progress shows Cloning and then, if verify is on, Verifying.

Rules

  • A and B must be different disks.
  • B must be at least as big as A, down to the byte. Same-label cards from different brands often differ by a few megabytes, so if the clone refuses, use a bigger card, or back up A and restore it instead (that only needs room for the used part of the image).
  • Both disks are looked up again after you confirm, so swapping a card while the dialog was open gets caught.

How it works

It's the same as a restore, just reading from a disk instead of a file. A's volumes get a best-effort lock (you'll get a note if one couldn't be locked, and should leave that drive alone until it's done). B's volumes must be locked and dismounted or the clone won't start. B's first 4 MiB is blanked first and written last, so a clone that stops partway leaves B blank. With verify on, all of B is read back and its SHA-256 compared with what was read from A.

The compress option has no effect on clones, and no .hash.txt is written since there's no file.
