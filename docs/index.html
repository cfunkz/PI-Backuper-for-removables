PI-Backuper

Back up, restore and clone Raspberry Pi SD cards (and any other USB drive) on Windows, macOS and Linux. Raw, sector by sector, with checks at every step so a bad card or a pulled cable doesn't cost you your setup.

What it does

You spent an evening getting a Pi set up just right. PI-Backuper takes a full copy of that SD card and saves it as a file on your PC. When the card dies, or you break something, you write the file back to a card and you're exactly where you were.

  • Backup reads a whole card into an .img or .img.gz file.
  • Restore writes an image file back onto a card.
  • Clone copies one card straight onto another, no file in between.

It copies the disk byte for byte, so it doesn't care what's on it. Raspberry Pi OS, Ubuntu, LibreELEC, a Windows installer stick, an encrypted drive: if your computer sees it as a removable or USB disk, it works.

Why bother with this one

  • Verify after writing. Everything written is read back and hashed. That's how you find out a card is fake or worn out before you rely on it.
  • SHA-256 hash next to every backup, so a damaged image is caught before it gets written to a card.
  • No half-restored cards. If a restore stops partway, the card comes out blank, not "boots and then corrupts itself".
  • Hard to point at the wrong disk. Only removable disks are listed, never the one your system runs from, and the disk is re-checked after you confirm.
  • Fast. Reading and writing happen at the same time, and compression is tuned so it doesn't hold back fast readers.
  • Portable. One .exe, no Python, nothing to install.
