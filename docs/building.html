Building from source

Run it from Python, build your own exe, and run the tests.

Requirements

  • Windows 10 or 11
  • Python 3.10 or newer, with Tkinter (it's included in the python.org installer)
  • The two runtime packages: pywin32 and WMI

Run from source

Open a terminal as Administrator, then:

git clone https://github.com/cfunkz/PI-Backuper.git
cd PI-Backuper
pip install -r requirements.txt
python main.py

python -m pi_backuper works too. On anything other than Windows, main.py exits straight away with "PI-Backuper only runs on Windows."

Build the exe

pip install -r requirements.txt pyinstaller

pyinstaller --onefile --noconsole --uac-admin --name PI-Backuper ^
  --icon favicon.ico ^
  --add-data "favicon.ico;." ^
  main.py

The result is dist\PI-Backuper.exe. What the flags do:

FlagWhy
--onefileOne portable exe instead of a folder.
--noconsoleNo black console window behind the app.
--uac-adminAsks for admin rights on launch, so users don't have to right-click.
--icon favicon.icoIcon for the exe file in Explorer.
--add-data "favicon.ico;."Bundles the icon so the window's title bar can use it too.

The ^ characters are line continuations for cmd.exe. In PowerShell use a backtick ` instead, or put it all on one line.

Tests

The imaging code doesn't depend on Windows, so the tests run anywhere, including Linux and macOS:

pip install pytest
python -m pytest

They run backup, restore and clone against fake in-memory disks. Among other things they check:

  • backup then restore gives back identical data, compressed and uncompressed
  • a gzip image that doesn't end on a sector boundary leaves the rest of that sector alone
  • old MD5 hash files still work
  • a damaged image is refused and the disk is left blank
  • an image too big for the device is refused before anything's written
  • verify catches a card that silently drops writes
  • clone copies everything and refuses a smaller target
  • a cancelled or failed backup leaves no files behind
  • a write error stops the reader thread too
  • a new backup replaces an old hash file

GitHub Actions runs the tests on Ubuntu and Windows for every push and pull request. On Windows it also checks that the Windows-only modules import cleanly.

Project layout

main.py                  entry point (what PyInstaller builds)
pi_backuper/__init__.py  name, version, author, licence
pi_backuper/__main__.py  lets you run "python -m pi_backuper"
pi_backuper/imaging.py   backup / restore / clone / verify, no Windows code
pi_backuper/windisk.py   finding disks, raw access, volume locking (Windows only)
pi_backuper/gui.py       Tkinter window
pi_backuper/fmt.py       "29.7 GB" and "3m 05s left" formatting
tests/                   tests for imaging.py using fake in-memory disks
favicon.ico              app icon
requirements.txt         pywin32, WMI
pyproject.toml           package metadata
