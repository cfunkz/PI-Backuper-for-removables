Getting started

What you need, how to run it, and a quick tour of the window.

What you need

  • Windows 10 or 11, macOS 12 or newer, or a 64-bit Linux (Raspberry Pi OS Bookworm, Ubuntu 22.04, Debian 12 or newer)
  • An administrator account (raw disk access needs it)
  • A USB SD card reader, or a built-in SD slot
  • Free disk space for your backups. A compressed backup of a mostly empty card is small, but plan for up to the full card size.

Download and run

Grab the file for your system from the Releases page:

SystemFile
WindowsPI-Backuper-…-windows-x64.exe
Mac with Apple silicon (M1 and newer)PI-Backuper-…-macos-arm64.zip
Intel MacPI-Backuper-…-macos-x64.zip
Linux PCPI-Backuper-…-linux-x64.tar.gz
Raspberry Pi (64-bit OS) and other ARM LinuxPI-Backuper-…-linux-arm64.tar.gz

Windows

Double-click the exe and say yes to the UAC prompt; it asks for admin rights by itself. SmartScreen may warn about an unknown publisher because the exe isn't code-signed. Click More info and then Run anyway, or build it yourself.

macOS

Unzip it and move PI-Backuper.app to Applications. The app isn't signed by Apple, so the first time, right-click it and pick Open (or run xattr -dr com.apple.quarantine /Applications/PI-Backuper.app). It asks for your password because raw disk access needs root.

Linux

tar xzf PI-Backuper-*-linux-*.tar.gz
./PI-Backuper

It offers to restart itself as root through your desktop's password prompt (pkexec). Without one, run sudo ./PI-Backuper. USB disks and SD cards are listed; the disk your system runs from never is.

Then put your SD card in the reader and press Refresh if it doesn't show up straight away.

The window

SectionWhat it's for
DeviceThe card you're backing up from or restoring to. Refresh re-scans for disks.
BackupWhere to save the image. Save as… picks a file, Start backup runs it.
RestoreWhich image to write. Open image… picks a file, Start restore runs it. Erases the device.
CloneCopy disk A onto disk B. Erases B.
OptionsGzip compress backups and Verify after writing. Both are on by default.
Progress (bottom)Current step, bytes done, percentage, speed and time left. Cancel stops the job.

Each disk in the lists looks like this:

Disk 2: Generic STORAGE DEVICE USB Device #000000001536  |  29.7 GB  |  E: F:

On Windows that's the disk number, the reader's model name, its serial if it has one, the size, and any drive letters Windows gave the card's partitions. A Pi card usually only shows one letter (the small boot partition) because Windows can't read the Linux one.

Your first backup

  1. Pick the card under Device.
  2. Click Save as… and choose a name, for example pihole-2026-10.img.gz.
  3. Leave both options ticked and click Start backup.
  4. Wait for "Backup complete and verified". You'll have two files: the image and a small .hash.txt beside it. Keep them together.

That's it. The other pages go through each job in more detail.
